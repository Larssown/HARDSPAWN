# HARDSPAWN — vald logga B

Symbol B (Rörelse) är nu kombinerad med det valda ordmärket. HARD är ljust och hela SPAWN är rött.

- `hardspawn_logo.svg` / `.png`: transparent huvudlogga för spelets meny.
- `hardspawn_emblem.svg` / `.png`: transparent symbol B för spelikon och framtida introanimation.
- `hardspawn_preview.png`: förhandsvisning mot mörk bakgrund.

SVG-filerna innehåller endast vektorformer och kräver inget externt typsnitt.
